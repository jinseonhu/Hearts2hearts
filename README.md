# 하투하 일정 모아보기

하츠투하츠(하투하) 공연, 축제, 시상식, 팬 이벤트 일정을 한 페이지에서 보는 앱입니다.

## 파일 구성

- `events.json` : 일정 데이터. 여기에 일정을 추가하거나 고치면 됩니다.
- `index.html` : 일정을 보여주는 웹페이지. 브라우저에서 열면 됩니다.
- `README.md` : 지금 보고 있는 설명서입니다.

## 사용 방법

1. `index.html`을 브라우저(크롬, 사파리 등)로 엽니다.
   - 주의: `events.json`을 불러오므로, 파일을 더블클릭하면 일부 브라우저에서 목록이 안 보일 수 있습니다.
   - 이 경우 폴더에서 `python3 -m http.server 8000` 을 실행한 뒤 `http://localhost:8000` 에 접속하세요.
2. 상단 버튼으로 종류(축제, 시상식 등)를 골라 볼 수 있습니다.
3. 지난 날짜의 일정은 자동으로 숨겨집니다.

## 일정 추가 방법

`events.json`의 `events` 목록에 아래 형식으로 한 덩어리를 추가합니다.

```json
{
  "date": "2026-12-31",
  "title": "행사 이름",
  "type": "축제",
  "place": "장소",
  "status": "공식 발표 확인 (출처)",
  "source": "https://출처-링크"
}
```

- `date` : 날짜 (년-월-일 순서, 예: 2026-12-12)
- `type` : 축제, 시상식, 팬 이벤트, 방송 중 하나를 쓰면 버튼이 자동으로 생깁니다.
- `status` : 확인 상태입니다. "공식 발표 확인"이라는 글이 들어가면 초록색으로 표시됩니다. 팬 계정이나 달력 정보는 "확인 필요"라고 적어 두세요.

## 자동 수집에 대하여

인스타그램, X, 위버스는 로그인이 필요하거나 자동 접근을 막고 있어서, 지금 버전은 일정을 사람이 직접 `events.json`에 입력하는 방식입니다. 자동 수집을 원하면 로그인 계정 연결 등 추가 작업이 필요합니다.
